## Test Image Specifications

Each image should be:
- High quality and clearly visible
- Contain relevant content for its category
- Be appropriately sized (1-5MB)
- Include metadata about expected responses
- Have clear, testable elements

## Usage in Tests

These images will be used with corresponding test cases that:
- Ask specific questions about the image content
- Expect particular elements to be identified
- Test different aspects of vision model capabilities
- Provide scoring criteria for responses
